# حالت مستقیم (بدون واسطه) — چه چیزی ممکن است و چه چیزی نه

## واقعیت فیزیکی

اگر هیچ واسطه‌ای (رله/VPN) در مسیر نباشد، ترافیک بازی از همان مسیری می‌رود که ISP شما تعیین می‌کند.
**هیچ اپی نمی‌تواند مسیر را عوض کند بدون اینکه کسی مسیر را عوض کند.** بنابراین «بهبود پینگ بدون واسطه»
در بهترین حالت یعنی کم‌کردن نوسان و تأخیرهای سمت دستگاه و شبکه‌ی محلی — نه کوتاه‌تر کردن فاصله‌ی شبکه.

آنچه در حالت مستقیم **واقعاً** انجام می‌شود:

| کار | نیاز به روت | اثر واقعی |
| --- | --- | --- |
| اندازه‌گیری مسیر واقعی (TCP/UDP) با برچسب `direct (no relay)` | نه | فقط سنجش؛ مبنای مقایسه |
| ICMP واقعی (ping) | بله | دیدن مسیر و loss واقعی |
| Wi-Fi power save off | بله | کم‌کردن جهش تأخیر روی وای‌فای |
| **bufferbloat guard: `tc qdisc fq_codel`** | بله | وقتی برنامه‌ی دیگری آپلود را پر می‌کند، تأخیر بازی جهش نمی‌کند |
| BBR برای TCP | بله | throughput بهتر روی لینک پرافت (RTT را کم نمی‌کند) |
| Doze whitelist | بله | اتصال پایدارتر در پس‌زمینه |
| drop_caches | بله | آزادسازی یک‌باره حافظه (اثر کوتاه) |

آنچه **امکان‌پذیر نیست** و ادعا هم نمی‌شود:
- کم‌کردن فاصله‌ی شبکه تا سرور بازی (تنها راه: مسیر جایگزین = رله).
- دور زدن محدودیت ISP بدون واسطه.
- تغییر مسیر فقط برای بازی، بدون VPN یا رله.

## چطور استفاده کنم

1. تب **Home** → کارت «حالت اتصال» → دکمه **مستقیم**.
2. اگر روت دارید: **Settings → Root mode** را روشن کنید و سوییچ‌های
   «Bufferbloat guard (fq_codel)»، «Wi-Fi power save off»، «Whitelist در Doze» را فعال کنید.
3. در Home دکمه‌ی **Apply device tuning** همین‌ها را اعمال می‌کند (و در Disconnect/بازگردانی برمی‌گردد).
4. تب **Measure**: همان target را اندازه بگیرید؛ مسیر گزارش `direct (no relay)` است.
5. برای مقایسه‌ی منصفانه: یک‌بار مستقیم، یک‌بار با رله، **همان target** و **همان شبکه**.

## نکته‌ی صادقانه

اگر مسیر ISP شما به سرور بازی خوب است، حالت مستقیم بهترین انتخاب است. اگر بد است (پکت‌لاس، مسیر
غیرمستقیم، پورت‌های فیلترشده)، تنها راه واقعی تغییر مسیر همان رله است. حالت مستقیم راهی برای
«بهبود بدون واسطه» نیست؛ راهی برای **اندازه‌گیری درست** و **حذف نوسان‌های سمت دستگاه** است.
