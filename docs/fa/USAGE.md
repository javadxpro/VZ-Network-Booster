# نصب و استفاده

> خلاصه‌ی عملی و گام‌به‌گام: [`QUICKSTART.md`](QUICKSTART.md)

## ۱) نصب APK

- از Artifact گیت‌هاب: Actions → آخرین اجرای سبز → `vz-network-booster-debug-apk` → نصب روی گوشی.
- یا بسازید: `make apk` و سپس `adb install -r dist/app-debug.apk`.

APK دیباگ است (امضای debug، `applicationId` با پسوند `.debug`). برای انتشار، keystore خودتان را
بسازید و `assembleRelease` بگیرید؛ کلید امضا هرگز داخل مخزن نباشد.

## ۲) آماده‌سازی یک رله واقعی (اجباری)

اپ از پیش هیچ رله‌ای ندارد، چون رله WireGuard بدون ثبت کلید عمومی این دستگاه کار نمی‌کند.
مراحل کامل: [`config/relay-setup-example.md`](../../config/relay-setup-example.md)

خلاصه:
1. روی سرور: `wg genkey`/`wg pubkey` و `wg-quick up wg0`.
2. در اپ: Settings → Device identity → *Copy public key*.
3. روی سرور: `wg set wg0 peer <DEVICE_PUBLIC_KEY> allowed-ips 10.66.0.2/32`.
4. در اپ: Relays → Add relay → چسباندن bundle (JSON) یا کانفیگ کلاینت wg-quick،
   یا دکمه‌ی **Choose file…** برای انتخاب فایل `.conf` / `.json` از حافظه‌ی گوشی.

## ۳) استفاده روزمره

1. **Games**: بازی هدف را انتخاب کنید (PUBG Mobile Global از ابتدا هست). اگر می‌خواهید کیفیت مسیر
   بازی اندازه‌گیری شود، یک *Probe target* اضافه کنید (host:port واقعی که می‌شناسید).
2. **Relays**: رله را اضافه کنید، سپس *Check health*. اگر رله probe target نداشته باشد وضعیت
   «unverified» است — این یعنی اندازه‌گیری نشده، نه اینکه سریع است.
3. **Home**: دکمه Connect → اندروید پنجره رضایت VPN را نشان می‌دهد → تونل بالا می‌آید.
   کارت وضعیت: relay، phase، uptime، ترافیک، تعداد reconnect.
4. **Measure**: قبل از اتصال و بعد از اتصال، همان target را اندازه بگیرید؛ مسیر در گزارش
   (`direct` یا `tunnel:<name>`) مشخص است. این تنها مقایسه معتبر است.
5. **Optimize route**: رله‌ها یکی‌یکی بالا می‌آیند، از داخل همان تونل اندازه‌گیری می‌شود و بهترین
   مسیر بر اساس عدد واقعی انتخاب می‌شود.

## ۴) معنی اعداد

- **avg / min / max**: میانگین و بازه RTT دست‌دادن TCP (یا رفت‌وبرگشت UDP).
- **jitter**: میانگین قدرمطلق اختلاف نمونه‌های متوالی (همان ایده |D| استاندارد RFC 3550، بدون هموارسازی).
- **loss**: درصد تلاش‌هایی که پاسخی نگرفتند.
- **UDP بدون پاسخ**: طبیعی است؛ سرورهای بازی به datagram ناشناس پاسخ نمی‌دهند. گزارش صریحاً
  «no UDP reply» می‌نویسد و عدد جعل نمی‌کند.

## ۵) Split Tunneling

با فعال بودن «game apps only»، فقط پکیج‌های بازی فعال + خود اپ (برای اندازه‌گیری) از تونل عبور می‌کنند؛
بقیه ترافیک گوشی دست‌نخورده می‌ماند. برای غیرفعال کردن، سوییچ Settings را خاموش کنید تا تونل کامل شود.

## ۶) Auto Reconnect

Watchdog هر ۵ ثانیه وضعیت را بررسی می‌کند؛ در صورت قطع، با backoff نمایی (۲s، ۴s، ۸s … حداکثر ۳۰s)
دوباره وصل می‌شود. تعداد تلاش‌ها در کارت وضعیت دیده می‌شود.
